# Texas Students First

A plain-language website for Texas parents about school attendance rules and a proposal for 10 protected sick days.

- **Today's Rules:** the 90% rule, excused vs. unexcused absences, and serious illness certificates, based on the TEA 2026–2027 Student Attendance Accounting Handbook.
- **The Proposal:** 10 protected sick days, with an attendance calculator.
- **Letter to Lawmakers:** a letter parents can personalize and copy.

Live at https://texasstudentsfirst.com (published with GitHub Pages from the `main` branch).

To edit, change `index.html` and push to `main`.
